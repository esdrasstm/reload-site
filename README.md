# Reload Estúdio

Site da Reload Estúdio: [reloadestudios.com.br](https://reloadestudios.com.br)

HTML, CSS e JavaScript puros, sem etapa de build. As animações usam o GSAP via CDN.

- `index.html`: a página
- `css/style.css`: estilos (layout do Figma, desktop 1920 e mobile 700)
- `js/main.js`: menu, cards de projetos, brilho dos botões e formulário
- `assets/`: imagens e ícones exportados do Figma

Hospedado no GitHub Pages a partir da branch `main`. O arquivo `CNAME` define o domínio.
